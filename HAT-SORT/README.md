# HAT-SORT

## :mag: Overview

In this project, we apply our proposed **H**istory-**A**ware **T**ransformation (**HAT**) to SORT-like framework, which is the most widely used codebase in the MOT field.
Our method **leverages historical trajectory information during inference to remap the appearance feature space**. This allows us to identify **a more discriminative representation space**, thereby enhancing the ReID branch of SORT-like frameworks.
Consequently, we can enhance tracking performance on-the-fly for specific inference sequences in a training-free manner.
